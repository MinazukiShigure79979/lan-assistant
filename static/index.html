语言模型服务

选择回答和字幕翻译使用的语言模型服务；本地模型、DeepSeek 或其他 OpenAI 兼容 API 都在这里切换。

对所有工作区生效
本地模型：回答和字幕翻译都在本机完成，音频和文字都不上传，离线可用。
DeepSeek 官方专用接口 地址、模型和关闭思考都已预填，通常只需要填 API Key。
获取 API Key ↗
API Key 使用 Windows DPAPI 加密，只保存在当前电脑；复制项目或迁移到新电脑后必须重新填写。
使用 API 时，回答和字幕文本会发送给该服务商。DeepSeek 默认会用 deepseek-flash，并关闭思考模式。

悬浮字幕外观

控制听读翻译悬浮字幕的字体、字号和颜色；保存后立即应用，不改动主界面字幕。

默认：Microsoft YaHei UI，原文 15 号、译文 23 号，原文 #f4f8fd、译文 #ffffff。旧字幕会自动降亮度。

延迟与性能
